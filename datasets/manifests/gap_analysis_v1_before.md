2. **段階評価**: 41 問すべて 5 段階。3・7・10 段階は 0。photo と txt には段階評価がない。
3. **ひねった問**: 否定 14（すべて rsn。photo は 0）、「該当なし」が正解 4、位置関係 59（photo は 4）、矛盾 12、不確かさ 8。photo の 1265 問の 76%（967）は「認識」。
4. **日本語固有**: 0 問（全 1841 問が en・ja の両方）。**文章のみの対照**: 画像の問と対にした対照は 0 組。
5. **はい/いいえ**: 全体は 197:194 でほぼ均等。偏りは ID の区間に出る（photo-1151〜1268 の 45 問連続「いいえ」、photo-0768〜0794 の 27 問連続「いいえ」。txt は「はい」60%、rsn は 44%）。画像の種類・skill・難度で切っても大きくは偏らない（rsn の rules 1:5、contradiction 4:8 は件数が小さい）。
